# CampusBite

CampusBite is a campus food-ordering platform with three roles (student, restaurant owner, admin). It consists of a React frontend (`frontend/`) and a FastAPI backend (`backend/`) backed by PostgreSQL, with AI-generated order insights through the OpenAI API.
